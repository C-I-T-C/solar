# 🌌 Persian Solar System (شبیه‌ساز سه‌بعدی منظومه شمسی)

یک شبیه‌ساز سه‌بعدی تعاملی و زیبا از منظومه شمسی به زبان فارسی، طراحی شده با کتابخانه قدرتمند **Three.js** و موتور باندل‌کننده **Vite**. این پروژه شامل اطلاعات دقیق علمی، آزمون‌های ستاره‌شناسی، قابلیت مقایسه سیارات و ابزارهای کنترل زمان است.

---

## ✨ ویژگی‌های برجسته پروژه

- **شبیه‌سازی سه‌بعدی واقع‌گرایانه:** طراحی و پیاده‌سازی سیارات و خورشید با بافت‌های باکیفیت و سیستم نوری Real-time.
- **کاملاً فارسی و علمی:** اطلاعات دقیق درباره هر جرم آسمانی (قطر، فاصله از خورشید، دوره تناوب مدار و...) کاملاً به زبان فارسی.
- **کمربند سیارکی و دنباله‌دارها:** وجود کمربند سیارکی متحرک و ایجاد دنباله‌دارهای پویا در پس‌زمینه.
- **موتور کنترل زمان (Time Engine):** قابلیت توقف، افزایش یا کاهش سرعت چرخش مداری و وضعی سیارات.
- **بخش آزمون (Quiz):** شامل کوئیزهای تعاملی و جذاب درباره ستاره‌شناسی برای سنجش اطلاعات کاربر.
- **بخش مقایسه سیارات:** ابزاری برای مقایسه مقیاس و ویژگی‌های فیزیکی سیارات در کنار یکدیگر.
- **طراحی مدرن و کاملاً واکنش‌گرا (Responsive UI):** بهینه‌شده با فونت‌های زیبای فارسی و آیکون‌های Lucide.

---

## 🛠️ فناوری‌های استفاده شده

- **Three.js:** پیاده‌سازی محیط سه‌بعدی، دوربین، نورپردازی و بافت‌ها.
- **Vite:** باندلر سریع و مدرن برای توسعه وب.
- **GSAP (GreenSock):** انیمیشن‌های روان و انتقال‌های جذاب رابط کاربری.
- **Lucide Icons:** آیکون‌های مدرن و زیبا.
- **HTML5 / CSS3 / JavaScript (ES6+):** ساختاردهی و کدهای عملکردی.

## 🚀 راهنمای راه‌اندازی و اجرای پروژه روی سیستم شما

برای اجرای پروژه در محیط محلی خود، مراحل زیر را به ترتیب طی کنید:

### پیش‌نیازها
ابتدا مطمئن شوید که **Node.js** روی سیستم شما نصب است.

### ۱. کلون کردن مخزن
کدها را از گیت‌هاب دانلود یا کلون کنید:
```bash
git clone https://github.com/C-I-T-C/solar.git
cd solar
```

### ۲. نصب پکیج‌ها (Dependencies)
با استفاده از npm، پکیج‌های پروژه را نصب کنید:
```bash
npm install
```

### ۳. اجرای سرور توسعه (Local Server)
پروژه را به صورت زنده در سیستم خود اجرا کنید:
```bash
npm run dev
```
پس از اجرای دستور فوق، آدرسی مانند `http://localhost:5173` در اختیارتان قرار می‌گیرد که با باز کردن آن در مرورگر، می‌توانید پروژه را مشاهده کنید.

### ۴. بیلد گرفتن برای هاست (Production Build)
برای تولید کدهای بهینه‌شده جهت آپلود روی هاست یا GitHub Pages، دستور زیر را بزنید:
```bash
npm run build
```
پوشه خروجی نهایی شما با نام `dist` ایجاد خواهد شد.
